Features

Completely Offline

All AI processing runs locally on your Mac. No internet connection required. Your notes stay on your device.

Lightweight App

Native macOS application optimized for Apple Silicon. Minimal resource usage with efficient memory management.

Fast Performance

Metal GPU acceleration provides quick AI responses. Instant search across all notes with semantic understanding.

Expandable

Create custom tools with your own prompts. Configure temperature, tokens, and stop sequences for each tool.

Instant AI Support

Built-in autocomplete, text correction, rephrasing, summarization, and translation available in every note.

Multiple Models

Choose from 8 models. Download models on first launch (~700MB each), larger models available for Pro users.

Chat Interface

Conversational AI assistant within the app. Ask questions, get help with writing, or brainstorm ideas with context-aware responses.

Persistent Storage

Notes and AI conversations are automatically saved. Access your entire history anytime with full-text and semantic search.

Markdown Support

Write using Markdown syntax with live preview. Export notes to various formats while maintaining formatting.

Installation Steps

  • Download and open the DMG file
  • EASY: Double-click "Install ZetaNotes.command" (automatic)
  • OR drag ZetaNotes to Applications manually
  • If manual: RIGHT-CLICK → Open → Click "Open" in warning
  • After first launch, you can open normally

System Requirements

  • macOS 13.0 (Ventura) or later
  • Apple Silicon (M1/M2/M3/M4) recommended
  • 4 GB RAM minimum (8 GB+ recommended)
  • 2 GB disk space (includes app + AI models)
