Download & Install OffNotes

Get started with private, offline AI note-taking in minutes.

Latest Version: v1.0.0

macOS 13.0+ • Apple Silicon Optimized

Download OffNotes.dmg
Download size: ~800 MB (includes TinyLlama model)

Installation Instructions

Open the DMG file

Double-click the downloaded OffNotes.dmg file to mount it.

Drag to Applications

Drag the OffNotes app icon to your Applications folder.

Open OffNotes

Right-click on OffNotes in Applications and select "Open".

After the first launch, you can open the app normally.

Grant Permissions

OffNotes may request permissions for:

  • Network Access: Only used to download additional AI models (optional)
  • File Access: To save your notes locally

All AI processing happens offline. No data is ever uploaded.

Start Taking Notes!

You're all set! The free TinyLlama model is bundled with the app, so AI features work immediately.

System Requirements

  • Operating System: macOS 13.0 (Ventura) or later
  • Processor: Apple Silicon (M1/M2/M3/M4) recommended for best performance
  • Memory: 4 GB RAM minimum, 8 GB+ recommended
  • Storage: 1 GB for app + TinyLlama model
    • Open-Source models: 0.7-2.3 GB each (optional)
ℹ️ Intel Mac Support

OffNotes works on Intel Macs but is optimized for Apple Silicon. Expect slower AI performance on Intel processors.

Troubleshooting

App won't open or crashes on launch

  • Make sure you're running macOS 13.0 or later
  • Try removing quarantine flag: xattr -cr /Applications/OffNotes.app
  • Check Console.app for crash logs

AI features not working

  • Ensure TinyLlama model is present (bundled with app)
  • Check Settings → AI Settings to verify model is loaded
  • Try restarting the app

Model downloads fail

  • Check your internet connection
  • Ensure you have enough disk space
  • Models are 0.7-2.3 GB each and downloaded from HuggingFace
