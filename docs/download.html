Installation Instructions

Open the DMG file

Double-click the downloaded OffNotes.dmg file to mount it.

Drag to Applications

Drag the OffNotes app icon to your Applications folder.

First Launch

Open OffNotes from your Applications folder. You may see a security warning on first launch.

⚠️ IMPORTANT: "OffNotes cannot be opened" warning

You WILL see this security warning. This is because OffNotes is not signed with an Apple Developer certificate ($99/year).

The app is safe. It's open source and you can verify the code on GitHub.

To open OffNotes:

  1. Right-click (or Control-click) on OffNotes in Applications
  2. Select "Open" from the menu
  3. Click "Open" in the security dialog

Alternative method:

  1. Try to open OffNotes normally (it will be blocked)
  2. Go to System Settings → Privacy & Security
  3. Scroll down and click "Open Anyway"
  4. Confirm by clicking "Open"

After the first time, you can open OffNotes normally (no right-click needed).

System Requirements

  • Processor: Apple Silicon (M1/M2/M3/M4) recommended for best performance
  • Memory: 4 GB RAM minimum, 8 GB+ recommended

ℹ️ Intel Mac Support

OffNotes works on Intel Macs but is optimized for Apple Silicon. Expect slower AI performance on Intel processors.

Troubleshooting

App won't open or crashes on launch

  • Make sure you're running macOS 13.0 or later
  • Try removing quarantine flag: xattr -cr /Applications/OffNotes.app
  • Check Console.app for crash logs

AI features not working

  • Ensure TinyLlama model is present (bundled with app)
  • Check Settings → AI Settings to verify model is loaded
  • Try restarting the app

Model downloads fail

  • Check your internet connection
  • Ensure you have enough disk space
  • Models are 0.7-2.3 GB each and downloaded from HuggingFace
