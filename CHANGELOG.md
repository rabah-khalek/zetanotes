# Changelog

All notable changes to ZetaNotes. The app is no longer maintained; 1.0.3 is the final release.

## 1.0.3 — October 2026

- ZetaNotes is now completely free: all former Pro features are unlocked for everyone.
- In-app purchases and subscriptions removed.
- Final release. The source code is published on GitHub under the MIT license.
- Notarized direct download available from GitHub Releases.

## 1.0.2 — November 7, 2025

- Qwen3 4B model support.
- Enhanced markdown preview with GitHub-flavored support (tables, task lists, images).
- Fixed title generation for the Llama 3.2 1B model.
- Tool output headers now use markdown heading format.

## 1.0.1 — November 6, 2025

- Qwen 2.5 3B and 7B model support.
- Bug fixes and performance improvements.
- Improved error handling and logging.

## 1.0.0 — November 5, 2025

- Initial App Store release.
- 8 AI models (Llama 3.2, Phi-3, Qwen 2.5, Gemma 2).
- AI autocomplete, correction, rephrasing, summarization, translation.
- Chat interface with conversational AI.
- Semantic search across all notes.
- Custom AI tool creation.
- Markdown support with live preview.
- Metal GPU acceleration for fast inference.
